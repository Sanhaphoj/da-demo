# 📦 ระบบจัดการครุภัณฑ์และตรวจสอบราคามาตรฐาน
> **Durable Articles Asset Management & Standard Budget Price Verifier System**
This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

ระบบเว็บบอร์ดหลังบ้าน (Backoffice Dashboard) ระดับพรีเมียมสำหรับการบริหารจัดการ ตรวจสอบ ตรวจรับ และวิเคราะห์สถิติมูลค่าสินทรัพย์ครุภัณฑ์สำนักงาน ครุภัณฑ์คอมพิวเตอร์ และหมวดหมู่อื่น ๆ ตามเกณฑ์ราคากลางมาตรฐานของสำนักงบประมาณ

### 1. แผงแดชบอร์ดสรุปผลและสถิติอัจฉริยะ (Interactive Analytics Dashboard)
* **การ์ดดัชนีชี้วัด (KPI Cards)**: แสดงมูลค่าครุภัณฑ์รวม, จำนวนสินทรัพย์แยกประเภท, อัตราความสอดคล้องตามเกณฑ์ราคากลาง และมูลค่าส่วนเกินงบประมาณที่หลุดเกณฑ์มาตรฐาน
* **แผนภูมิเปรียบเทียบ (Stunning Visual Charts)**: แผนภูมิแสดงสัดส่วนมูลค่าครุภัณฑ์สะสมแยกตามฝ่ายงาน และสัดส่วนหมวดหมู่ครุภัณฑ์โดยรวม พัฒนาบน Chart.js ลื่นไหลและรองรับการตอบสนองทุกอุปกรณ์
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 2. ระบบทะเบียนครุภัณฑ์เต็มรูปแบบ (Comprehensive Durable Articles Registry)
* **ตัวกรองค้นหาขั้นสูง (Advanced Filters)**: ค้นหาด้วยหมายเลขครุภัณฑ์, ชื่อเรียกพัสดุ, ชื่อผู้ดูแล หรือกรองแยกตามหมวดงบประมาณ, ฝ่ายที่สังกัด และสถานะราคากลางมาตรฐาน
* **ระบบจัดการความคืบหน้า (Progress workflow)**: ติดตามกระบวนการตั้งแต่เริ่มขออนุมัติจัดซื้อจัดจ้าง, การกำหนด TOR/ราคากลาง, ขั้นตอนตรวจรับพัสดุ ไปจนถึงการตรวจรับเสร็จสิ้นสมบูรณ์
* **ดูรายละเอียดด่วน (Quick Inspector Details)**: หน้าต่างดูภาพพรีวิวครุภัณฑ์ขนาดใหญ่เต็มตาโดยไม่ล้นหน้าจอ พร้อมรายละเอียดรหัสพัสดุ, ราคางบประมาณเสนอซื้อ, และลิงก์ดาวน์โหลดเอกสารคู่มือ PDF ในจุดเดียว
You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

### 3. ระบบแนบเอกสาร PDF และป้องกันไฟล์ขนาดใหญ่ (PDF Document Attachment & Size Guard)
* **ความปลอดภัยของฐานข้อมูล**: จำกัดการอัปโหลดไฟล์ PDF ไว้ไม่เกิน **500kB** เพื่อป้องกันการแบกรับขนาดไฟล์หน่วงหน้าจอและการบวมของข้อมูล Base64
* **การช่วยเหลือผู้ใช้ย่อไฟล์**: ระบบตรวจสอบขนาดไฟล์อัปโหลดอัตโนมัติ หากเกิน 500kB จะปฏิเสธและขึ้นข้อความแจ้งเตือนภาษาไทย แนะนำให้ย่อขนาดไฟล์ผ่านบริการฟรีก่อนแนบ เช่น `ilovepdf.com` หรือ `smallpdf.com` เพื่อรักษาสเปกและอักขระให้ยังคงสืบค้นได้ (Searchable)
* **การเรียกดูสะดวก**: แสดงตราสัญลักษณ์รูป **`📄 PDF`** สีฟ้าสะดุดตาในตารางหลัก เมื่อคลิกจะเปิดสตรีมเอกสารอ่านบนแท็บใหม่ของบราวเซอร์ได้ทันที

### 5. ระบบตรวจสอบราคากลางมาตรฐาน (ICT & Budget Price Verifier Sandbox)

### 6. ระบบส่งออกรายงาน Excel คัดกรองตามห้วงเวลา (Flexible Excel Reporter)
* **การคัดเลือกช่วงเวลา**: ส่งออกรายการครุภัณฑ์เป็นรายงานเอกสาร Excel ทางการ (.xls) โดยเลือกเงื่อนไขได้ละเอียด:

### 7. โครงสร้างความปลอดภัยและการจัดการสิทธิ์สมาชิก (Dynamic Auth & Settings)
* **ระบบจัดกลุ่ม Cascade**: ฟอร์มลงทะเบียนครุภัณฑ์ที่กล่องตัวเลือกฝ่ายงานและกลุ่มงานหลักจะแสดงความเชื่อมโยงแบบลดหลั่น (Cascade Select) สอดคล้องตามพจนานุกรมฝ่ายงานย่อยที่ตั้งค่าจริงในผังองค์กร
* **การคำนวณรหัสผ่านพรีเมียม**: ฟอร์มสมัครสมาชิกพร้อมแถบวัดระดับความปลอดภัยรหัสผ่าน (Password Strength Meter) และตัวดักตรวจสอบเงื่อนไขความเข้มงวดความปลอดภัยของรหัสผ่าน
* **การจัดการสิทธิ์**: ผู้ดูแลระดับสูงสามารถปรับเปลี่ยนสิทธิ์ผู้เข้าใช้งานได้อย่างอิสระ (Super Admin / Admin / Viewer)

## 🛠️ การติดตั้งและเริ่มรันระบบในเครื่อง (Local Run Guide)

โปรเจกต์นี้เขียนและคอมไพล์บนเฟรมเวิร์ก **Next.js (React)** ซึ่งเป็นระบบออฟไลน์ทำงานร่วมกับฐานข้อมูลเบราวเซอร์ (LocalStorage) เป็นมาตรฐานหลักหากไม่มีการกำหนดคีย์คลาวด์ Firebase

### 1. ความต้องการของระบบ (Prerequisites)
* ติดตั้งเครื่องมือ [Node.js](https://nodejs.org/) (แนะนำเวอร์ชัน 18.x หรือ 20.x ขึ้นไป)

### 2. ขั้นตอนการรันระบบ
1. แตกไฟล์โครงการหรือโคลนโครงการมาจาก GitHub
2. เปิดโปรแกรม Terminal หรือ Command Prompt ในโฟลเดอร์โครงการ
3. ติดตั้งโมดูลและแพ็กเกจที่จำเป็นสำหรับโครงการ:
   ```bash
   npm install
   ```
4. เริ่มรันเซิร์ฟเวอร์สำหรับพัฒนาระบบ (Development Server):
   ```bash
   npm run dev
   ```
5. เปิดเบราว์เซอร์แล้วเข้าไปที่แอดเดรส:
   ```text
   http://localhost:3000
   ```

## 💾 สถาปัตยกรรมและไดรเวอร์ฐานข้อมูล (Database Drivers Config)

สำหรับผู้ที่ประสงค์จะต่อเชื่อมระบบฐานข้อมูลเข้าสู่เซิร์ฟเวอร์คลาวด์ของตนเอง ระบบรองรับการเปลี่ยนสลับชนิดฐานข้อมูลได้อย่างง่ายดายที่เมนู **"ตั้งค่าฐานข้อมูล"** (เฉพาะสิทธิ์ Super Admin):

1. **Local Storage DB**: (มาตรฐานเริ่มต้นของเดโม่) ไม่ใช้เซิร์ฟเวอร์ภายนอก ข้อมูลปลอดภัยและจัดเก็บในเครื่องเบราว์เซอร์ของผู้ใช้งานแต่ละคนแบบแยกอิสระ
2. **Cloud Firebase NoSQL**: เพียงนำชุดโค้ดเชื่อมต่อจากหน้าเว็บ Firebase Console (คีย์ `FIREBASE_CONFIG`) มากรอก ระบบจะถอดรหัสและเปลี่ยนโหมดซิงค์ข้อมูลสินทรัพย์ทั้งหมดข้ามเครื่องแบบเรียลไทม์ทันที!
3. **SQL Drivers**: รองรับโครงสร้างข้อมูลที่เชื่อมโยงกับฐานข้อมูลสัมพันธ์ระดับโปรดักชันอย่าง **PostgreSQL** และ **MySQL/MariaDB** ได้ทันทีในคอมพิวเตอร์ของคุณ
